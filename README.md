# Pocket Contraptions

⚠️Work in progress!!  

Creates pocket dimensions inside single blocks.  
Fit your whole minecraft world in one chunk!

## Features


`✅ Complete`  
`⚠️ Work In Progress`  
`❗️ Planned`


- Blueprints ✅
  - Item component to create Blueprint Builder recipes
- Blueprint Builder ✅
  - Uses item components to read recipes from any item
  - Turns one item into another by consuming ingredients from adjacent inventories
- Ghost Mode ⚠️
  - Allows the player to go through most blocks
  - Intended for building inside Pocket Contraptions
  - Activates when player places Pocket Contraption on head
- Pocket Contraption ❗
  - A block with a pocket dimension
  - Created in the Blueprint Builder
    - Add one Iron Block to increase the dimension size by 1 up to a max of 256
  - Put it on your head to build inside it as a ghost
  - Walls of the dimension reflect the sides of the block
    - Continue redstone lines, pass items, etc.
- Blueprint and Quill ❗
  - Generates a Blueprint for a pre-existing Pocket Contraption
  - Use Blueprint Builder and provide items to duplicate Pocket Contraptions
- Quantum Entangler ❗
  - Connect multiple Pocket Contraptions to the same pocket dimension
